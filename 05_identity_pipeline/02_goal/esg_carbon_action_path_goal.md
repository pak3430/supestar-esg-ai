# ESG Carbon Action Path Goal

ESG 책임이 측정·Scope·SDGs·감축·시장·산림탄소로 이어지는 이유를 선행관계가 보존된 최소 행동경로로 보여준다.

## Success

- 각 edge에 다음 단계가 필요한 이유와 근거가 있다.
- 측정 전제를 건너뛰고 상쇄·탄소중립으로 점프하지 않는다.
- 설명 카드와 다음 행동 체크리스트를 만든다.

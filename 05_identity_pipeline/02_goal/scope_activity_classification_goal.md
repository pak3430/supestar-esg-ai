# Scope Activity Classification Goal

조직·운영 경계와 활동의 소유·통제·구매에너지·가치사슬 관계를 사용해 Scope 1·2·3 후보를 재현 가능하게 판정한다.

## Success

- 분류 규칙과 입력값의 trace를 남긴다.
- 경계가 불명확하면 단일 Scope를 만들어내지 않는다.
- 활동자료가 없어도 Scope 후보와 배출량 계산을 구분한다.

# Scope Activity Classification Method

1. 조직·운영 경계가 존재하는지 확인한다.
2. 소유·통제 직접배출 규칙을 검사한다.
3. 구매에너지 규칙을 검사한다.
4. 남은 가치사슬 간접배출 규칙을 검사한다.
5. 규칙이 충돌하거나 입력이 부족하면 단일 후보를 만들지 않는다.
6. Scope 결과·근거 카드·추가자료 요청·RunRecord를 저장한다.

# ESG Carbon Action Path Method

1. 질문과 focus를 읽고 경로 종료점을 고른다.
2. 고정 인과축에서 종료점까지 필요한 노드를 순서대로 선택한다.
3. edge마다 이유와 source reference를 결합한다.
4. 측정 전제를 건너뛰는 확정 주장을 REVIEW 또는 STOP한다.
5. ActionPath·설명 카드·체크리스트·RunRecord를 저장한다.

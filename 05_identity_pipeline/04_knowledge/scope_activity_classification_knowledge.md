# Scope Activity Classification Knowledge

## Classification rules

- Scope 1: 조직이 소유하거나 통제하는 배출원의 직접배출.
- Scope 2: 구매해 소비한 전기·스팀·열·냉방 생산의 간접배출.
- Scope 3: Scope 2 외 상·하류 가치사슬의 기타 간접배출.
- Scope 3는 Scope 1과 Scope 2의 합이 아니다.
- 활동자료가 없으면 배출량을 계산하지 않는다.

# Forest Carbon Procedure Guidance Knowledge

## Ordered procedure

`사업계획 → 타당성·적격성 검토 → 사업등록 → 실행 → 모니터링 → 독립 검증 → 인증 → 거래 또는 비거래 활용 → 등록부 상태관리`

## Rules

- 현재 단계 완료 증거를 먼저 확인한다.
- 거래형·비거래형과 허용 표현을 임의 확정하지 않는다.
- 공개된 기관 업무 범위만 설명한다.
- 실제 등록·인증·상태변경은 실행하지 않는다.

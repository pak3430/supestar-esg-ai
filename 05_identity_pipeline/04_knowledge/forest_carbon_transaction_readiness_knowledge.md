# Forest Carbon Transaction Readiness Knowledge

## Gate model

- STOP 기본 게이트: G1 주체, G2 대상, G4 처분권, G5 적격성, G7 계약, G9 결제·정산, G10 등록부 이전.
- 조건부 게이트: G3 토지·사업권은 핵심권리 부재 시 STOP, 불명확 시 REVIEW.
- REVIEW 기본 게이트: G6 구매목적, G8 세무분류, G11 증빙·주장.
- 전체 우선순위: `STOP > REVIEW > PROCEED`.
- `PROCEED`는 법적 효력이나 거래 완료를 뜻하지 않는다.

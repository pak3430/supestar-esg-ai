# 초 ROK · 수페스타 최종 제출파일 안내

## 정확히 무엇을 만드는가

수페스타는 KAC 지식을 근거로 사용하고, KAC에서 구조화·배포한 Skill을 실행 규칙으로 사용하는 지식행동사슬 기반 스킬 실행형 ESG 챗봇이다.

사용자 질문을 Context로 구조화하고 관련 KAC와 Skill을 실제 실행해 `PROCEED·REVIEW·STOP`을 판정한다. 로컬 AI는 검증된 결과만 자연스럽게 설명한다. 산림탄소마켓은 모든 답변의 목적지가 아니라, 사용자가 구매처를 직접 물었을 때만 제공되는 외부 선택지다.

## 파일 우선순위

1. `초ROK_수페스타_예선기획서.pdf` — 검수 완료 7쪽 기획서 기본본
2. `초ROK_수페스타_예선기획서.docx` — 편집 가능한 기획서 원본
3. `초ROK_수페스타_시연영상.mp4` — 3분 26초, 1080p, 한국어 내레이션 기본본
4. `초ROK_수페스타_발표자료.pdf` — 검수 완료 11장 발표 기본본
5. `초ROK_수페스타_발표자료.pptx` — 편집 가능한 발표 원본
6. `초ROK_수페스타_시연영상_무음.mp4` — 동일 영상 스트림의 무음 보조본

공식 업로드 화면이 파일 수·형식·용량을 제한하면 기획서 PDF를 우선하고, 영상·발표자료는 허용 여부에 맞춰 추가한다.

## 핵심 시연 질문

1. `ESG가 무엇인가요?`
2. `저희 회사가 소유·운영하는 보일러에서 도시가스 1,250 Nm³를 2026년 8월에 사용했고 고지서가 있습니다. Scope 몇인가요?`
3. `회사 소유 보일러의 연료 사용과 구매전력을 한 질문에서 함께 분류해 주세요.`
4. `탄소크레딧은 어디에서 구매할 수 있나요?`
5. Scope 답변에서 `답변 근거와 실행기록 보기`를 펼친다.

명시적 구매 질문에서 제공하는 외부 선택지는 `https://forestcarbonmarket.kr/marketplace`이다. 프로젝트·가격·수량·인증·거래 조건은 해당 마켓에서 사용자가 직접 최신 상태를 확인한다.

## 확인할 실행 증거

- 사용자 진술에서 승격된 타입 Context
- `Identity → Goal → Task → Knowledge → Method → Skill` 체인
- 실제 실행한 Run Skill과 산출물
- `PROCEED·REVIEW·STOP` 판정
- Run ID, 파일 해시, 입력 바이트 보존, Output Risk Gate
- 일반 ESG 질문에서는 마켓 미노출, 명시적 구매 질문에서만 마켓 노출

## 실행 및 공개 주소 원칙

MVP는 로컬에서 실행 가능하다. 임시 터널 URL은 만료되므로 제출파일에 고정하지 않는다. 공개 URL이 공식 필수라면 제출 직전에 새 주소를 생성하고 외부 네트워크에서 홈·질문·상태 API를 재검증한 뒤 실제 제출란에만 기록한다.

## 책임 경계

수페스타는 해커톤 검증용 MVP이며 한국임업진흥원의 공식 운영 챗봇이 아니다. 실제 구매·결제·등록부 변경, 법률·세무·인증 최종판정, 실시간 시세·거래 보증을 수행하지 않는다.

## 제출 직전 외부 확인

- 공식 마감 시각
- 업로드 위치·허용 확장자·파일 수·용량
- 영상·PPT의 예선 필수 여부
- 수페스타 캐릭터 사용 허용 범위
- `SHA256SUMS.txt`와 실제 업로드 파일의 해시 일치

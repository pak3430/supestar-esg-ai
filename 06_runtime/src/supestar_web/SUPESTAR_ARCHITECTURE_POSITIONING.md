# 수페스타는 어떤 챗봇인가

## 한 줄 정의

수페스타는 **지식행동사슬에서 구조화한 지식을 질문별로 선택하고, 연결된 원자·복합 Skill을 실제로 실행한 뒤, 로컬 AI가 그 결과만 자연어로 설명하는 스킬 실행형 ESG 챗봇**이다.

## 두 관점 중 어디에 해당하는가

### 1. 지식 데이터를 쥐고 답하는 챗봇

이 기능도 가지고 있다. 질문이 들어오면 전체 문서를 모델에 한꺼번에 넣는 것이 아니라 관련 Identity를 고르고 다음 파일을 실제로 읽는다.

```text
Identity → Goal → Task → Knowledge → Method → Skill
```

선택된 파일과 원문 근거, SHA-256은 `kac_execution.json`에 기록된다. 이 부분만 보면 근거 기반 지식 챗봇과 비슷하다.

### 2. 지식행동사슬에서 나온 Skill로 동작하는 챗봇

수페스타의 더 중요한 특징은 이쪽이다. 질문을 설명하는 데서 끝나지 않고 다음 실행 Skill을 호출한다.

- ESG에서 탄소 행동경로 만들기
- Scope 1·2·3 분류
- CCM·VCM·배출권·크레딧 구분
- 산림사업 E/S/G 근거 매핑
- 산림탄소 현재 단계와 다음 절차 안내
- 거래 준비도 G1~G11 점검

이 Skill들이 구조화 입력을 받아 `PROCEED`, `REVIEW`, `STOP`과 산출물을 만든다. 로컬 AI는 이 결과를 변경하지 않고 자연스럽게 설명한다.

## 실제 구조

```text
사용자 질문
→ 사용자 진술을 구조화 입력으로 변환
→ Runtime Composite 단일 진입
   → 질문 라우팅
   → 관련 Identity·KAC 선택 및 파일 읽기
   → 필요한 원자 Run Skill 실행
   → 판정·근거·산출물 생성
→ 로컬 AI가 자연어로 설명
→ Output Risk Gate가 판정·권한·과장 여부 재검사
→ 사용자 답변
```

## 정확히 말해야 하는 경계

수페스타를 “지식 문서를 검색해 대답하는 일반 RAG 챗봇”이라고만 부르면 실제 Skill 실행 구조가 빠진다. 반대로 “챗봇 전체가 Stage Skill만으로 자동 생성됐다”고 말하면 웹 화면, 서버, Context 추출기, 실행 어댑터와 출력 게이트를 별도 코드로 만든 사실을 가리게 된다.

따라서 가장 정확한 표현은 다음과 같다.

> 수페스타는 KAC 지식을 근거로 사용하고, KAC에서 구조화·배포한 Skill을 실행 규칙으로 사용하는 지식행동사슬 기반 스킬 실행형 챗봇이다.

## 일반 RAG 챗봇과의 차이

| 구분 | 일반 지식/RAG 챗봇 | 수페스타 |
| --- | --- | --- |
| 지식 사용 | 관련 문서 조각 검색 | 관련 Identity의 6단계 KAC 파일 선택·해시 확인 |
| 판단 | 모델이 답변 속에서 수행하는 경우가 많음 | 원자 Run Skill이 구조화 결과와 판정 생성 |
| AI 역할 | 검색 결과를 바탕으로 답변·판단 | 검증된 결과의 자연어 표현만 담당 |
| 불충분한 입력 | 모델이 추정할 수 있음 | `REVIEW` 후 필요한 질문 제시 |
| 위험 요청 | 프롬프트 의존 | 라우터와 Output Risk Gate에서 결정론적으로 차단 |
| 실행 증거 | 인용 또는 검색 기록 | Context·KAC·Skill·Composite Run Record·산출물·해시 |

## 외부 소개 문장

> 수페스타는 ESG 문서를 단순 검색하는 챗봇이 아닙니다. 질문에 필요한 지식행동사슬을 선택하고, Scope 분류나 산림 ESG·절차·거래 준비도 Skill을 실제로 실행한 뒤, AI는 그 검증 결과만 이해하기 쉬운 말로 설명합니다.

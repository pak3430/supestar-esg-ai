# 추가성

## Meaning

추가성은(는) 산림 ESG 생태계에서 독립적으로 설명·판단되어야 하는 개념이다. 원문은 다음과 같이 이 구조적 역할을 뒷받침한다: “사업 설계·방법론 → 기준선·추가성 → 모니터링·검증 → 발행·등록 → 구매·이전 → 소각·사용완료 → 기후 주장. 자발성은 검증과 책임이 없다는 뜻이 아니다.”

## Boundary

- IS: 추가성 자체의 정의, 역할, 근거, 상태를 다루는 개념.
- IS NOT: 인접 시장·기관·절차·판정 개념을 대신하는 포괄 묶음.
- Entity boundary: 실제 프로젝트·기관·사용자·거래 인스턴스는 별도 실행·기록 계층에 둔다.

# 판매자

## Meaning

판매자은(는) 산림 ESG 생태계에서 독립적으로 설명·판단되어야 하는 개념이다. 원문은 다음과 같이 이 구조적 역할을 뒷받침한다: “판매자·구매자·중개자·결제사업자: 단위, 권한, 계약, 대금, 이전과 증빙의 책임을 나눈다.”

## Boundary

- IS: 판매자 자체의 정의, 역할, 근거, 상태를 다루는 개념.
- IS NOT: 인접 시장·기관·절차·판정 개념을 대신하는 포괄 묶음.
- Entity boundary: 실제 프로젝트·기관·사용자·거래 인스턴스는 별도 실행·기록 계층에 둔다.

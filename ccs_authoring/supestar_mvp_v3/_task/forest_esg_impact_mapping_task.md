# 산림 E/S/G 영향·책임 매핑 Task

## Required action

산림탄소 사업의 요약과 기준일을 받아 제공된 환경·사회·지배구조 증거를 축별로 분류하고, 각 축의 영향, 참여자, 책임, 증거, 공백과 확인 질문을 연결한 검토 가능한 지도를 작성한다.

## Inputs

- 필수: `projectSummary` — 사업 목적, 활동, 위치와 참여자에 관한 설명.
- 필수: `asOfDate` — 근거와 판단의 기준일.
- 선택: `environmentEvidence` — 흡수·저장, 생태, 방법론, 추가성, 누출, 영속성, 반전위험 자료.
- 선택: `socialEvidence` — 산주·임업인·지역사회, 권리, 참여, 동의, 편익과 안전 자료.
- 선택: `governanceEvidence` — 계획, 등록, 검증, 인증, 등록부, 계약과 감사 자료.

## Work to perform

1. 입력의 존재 여부와 기준일을 확인하고, 주장과 제공 증거를 분리한다.
2. 환경(E)에는 실제 흡수·저장 및 생태 영향과 방법론·경계·활동자료·모니터링·산정 증거를 배치한다.
3. 사회(S)에는 참여자, 권리·동의, 편익·부담·위험과 참여·안전·민원 증거를 배치한다.
4. 지배구조(G)에는 공개적으로 확인된 주체별 역할과 계획·검증·인증·등록부·계약·감사 증거를 배치한다.
5. 같은 자료를 여러 축에 놓아야 한다면 각 배치의 근거를 별도로 기록하고, 근거가 없으면 중복하지 않는다.
6. 축마다 영향, 참여자, 책임주체, 증거와 누락을 연결하고 누락별 확인 질문을 작성한다.
7. 세 축의 최소 정보와 책임주체가 모두 있으면 `PROCEED`, 일부 증거·권리·참여자·기관책임이 불명확하면 `REVIEW`, 사회·권리·거버넌스를 숨긴 채 흡수량만으로 ESG 완결을 요구하면 `STOP`으로 판정한다.
8. 구조화 지도, 사람이 읽는 지도, 누락축 질문과 입력·Identity·증거·누락·판정이 포함된 Run Record를 남긴다.

## Guardrails

- 제공되지 않은 영향, 권리, 동의, 책임 또는 기관 판단을 추정하지 않는다.
- 등록·검증·인증·거래의 완료나 법적 효력을 확정하지 않는다.
- 절차 안내, 거래 실행 또는 특정 기관을 대신한 승인으로 범위를 확장하지 않는다.

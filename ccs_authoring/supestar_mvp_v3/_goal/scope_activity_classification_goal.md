# Scope 활동 분류 Goal

## Aim

조직·운영 경계 안에서 활동자료의 소유·통제, 구매에너지, 가치사슬 관계를 점검하여 `SCOPE_1`, `SCOPE_2`, `SCOPE_3` 중 하나의 후보를 근거와 함께 판정한다.

## Success condition

- 경계와 관계정보가 일관되면 단일 Scope 후보와 적용 규칙을 제시한다.
- 정보가 불명확하거나 충돌하면 임의로 확정하지 않고 추가로 필요한 자료를 식별한다.
- Scope 정의를 위반하는 요구는 분류 결과로 받아들이지 않는다.
- 활동자료나 배출계수가 없는 상태에서는 배출량을 계산하지 않는다.

## Boundary

이 Goal은 활동의 Scope **후보 분류**를 목표로 한다. 온실가스 배출량 산정, ESG 전체 성과평가, 감축성과 판정은 이 체인의 목표가 아니다.

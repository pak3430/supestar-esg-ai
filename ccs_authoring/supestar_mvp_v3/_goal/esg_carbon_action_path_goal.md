# ESG→탄소 행동경로 Goal

## Fixed direction

ESG 책임을 측정·Scope·SDGs·직접감축·잔여배출·시장·산림탄소 행동으로 이어지는 최소 이유 경로로 바꾼다.

## Aim

`ESG_MANAGEMENT`가 말하는 행동과 책임을 사용자의 질문에 맞춰 측정, 조직·운영 경계, Scope 1·2·3, 활동자료와 배출계수, CO2e, 직접감축, 잔여배출, SDGs, 탄소시장과 산림탄소 프로젝트로 이어지는 최소 이유 경로로 바꾼다.

## Intended result

- 선행관계를 건너뛰지 않는 순서화된 ESG→탄소 행동경로를 만든다.
- 각 관계마다 다음 단계가 필요한 이유와 기준일이 있는 근거를 연결한다.
- 사용자가 이해할 설명 카드와 `확인할 자료`·`담당 주체`·`생성 산출물`로 나눈 다음 행동을 제시한다.
- 근거와 경계가 충분하면 `PROCEED`, 판단 전제가 부족하면 `REVIEW`, 측정 없는 탄소중립 확정이나 실제 거래 요구이면 `STOP`으로 제한한다.

## Boundary

이 Goal은 질문에 필요한 설명·판단 경로와 다음 행동을 생성하는 데 한정된다. 배출량을 임의로 산정하거나, 상쇄·탄소중립을 확정하거나, 크레딧 구매·등록부 변경·결제·법률·세무·인증 행위를 수행하지 않는다.
